Please follow the demonstration video for instructions. Additional information is given in this file:
1. When drawing a line, make sure that the start cell and the end cell are either in the same column or in the same line, otherwise nothing will be drawn. If you want to color multiple columns/lines use "draw rectangle".
2. When inserting a function for u/v/p please notice that the function will be evaluated at "x" or "y" (depending on the orientation of the line) in the range [0,1]. Therefore, make sure that the function features the desired behavior in [0,1]. Moreover, the function needs to produce values between [0,1] when inserting x or y values in [0,1]. The function should hence be normalized in [0,1]x[0,1].
3. For drawing the circle no drag and drop is implemented, please use the provided entries.
4. When generating from image, be aware that the rgb code of the image is directly copied into tbe editor (in the via "number cells in x and y" specified raster). Therefore, make sure that the picture is in rgb representation and when you like to draw an obstacle that the color is exactly black. The direct copy of the values is done in order to be able to reload a picture which was previously generated with the GUI. This picture can be found in the same foulder after pressing "generate" and is called "setup.png".
